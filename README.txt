AMBEDKAR AND HIS DHAMMA

Build: node build.mjs
Read offline: dist/Ambedkar_and_His_Dhamma.html
Preview: node preview.mjs

All styles, text and browser functionality are embedded in the HTML. External
source documents require internet access. Search, topic/type filters, saved
findings, citation copy, print and evidence JSON export work in a browser.
Saved finding IDs remain in that browser only; no account or tracking is used.

Expanded reading edition 02 adds 54 context/comparison blocks to all 38
findings, including eight additional source excerpts. Context is visible by
default and can be hidden with the reading controls. Citation copying and
JSON export include the surrounding summaries and their source locators.
Context paragraphs are editorial summaries, not verbatim transcripts.

content.mjs holds the original findings and source register.
contexts.mjs holds the expanded explanations and comparison quotations.
validate.mjs checks internal anchors, source keys, quotation lengths,
embedded data, and agreement between the website and offline edition.

The source register records printed pages, canonical locators, access limits
and the distinction between direct evidence, paraphrase and editorial inference.
No unverified quotation or page number should be added as an exact citation.
